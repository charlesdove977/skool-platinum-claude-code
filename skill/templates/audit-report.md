# Audit Report Template

Output file: `skool-platinum/audits/{YYYY-MM-DD}/skool-audit.md` (rendered to `skool-audit-master-class.pdf`)

```template
# Skool Master Class Audit: {group-names}
{YYYY-MM-DD} · Prepared for {owner-name} · Standard: Skool Platinum (October)

## Contents
[auto list of sections]

## 1. The one-page verdict
[3 sentences: where the group stands, the biggest lever, the first move]
| Area | Score /5 | Biggest gap | First fix |
|---|---|---|---|

## 2. Where you stand vs the Platinum target
[current MRR, members, price vs the Platinum milestone ladder and the cohort deadline]

## 3. Area-by-area
### {area}
- **Now:** [evidence + source]
- **Platinum standard:** [what good looks like + lesson/transcript source]
- **Competitors doing it well:** [name + URL]
- **Fix:** [specific change, rewritten copy if relevant]
- **Effort / impact:** {S/M/L} / {H/M/L}

## 4. Rewritten copy, ready to paste
[positioning line, description, about page, Start Here post]

## 5. Competitor snapshot
[table: name, price, members, positioning, link]

## 6. 7-day / 30-day / 90-day action plan
[checklist tables]

## 7. Sources
[every lesson, transcript timestamp, post, competitor URL used]
```

## Field Documentation
| Field | Type | Notes |
|---|---|---|
| {area} | variable | One per rubric area in checklists/audit-rubric.md |
| Scores | variable | 0–5 integer |
| Sources | prose | Clickable URLs in the PDF |

## Section Specifications
- **Clean and easy to read**: one idea per block, tables over paragraphs, white space, TOC.
- **Every recommendation carries a source.**
