## Field Documentation
| Field | Type | Notes |
|---|---|---|
| {group-name} | variable | A group from the profile's Groups table |
| [person], [result], [timeframe or method] | prose | Must come from the owner's answers, never invented |
| Ratings | variable | One of the listed values only |

## Section Specifications
- **Table**: only these seven fields; no modules, pricing, bonuses or guarantees.
- **Pressure test**: every rating gets an honest one-line reason.
- **Validate**: cheap actions with real people (interviews, offer-statement feedback, founding-member test).
