# Start Here Post Template

## Contents
- Template block (fenced)
- Field Documentation
- Section Specifications

Output file: `skool-platinum/setup/{group-slug}/{YYYY-MM-DD}/04-start-here-post.md`

```template
Title: [Start Here: welcome to {group-name} (read first)]

[Warm one-line welcome in the owner's voice (profile Voice section)]

You're here to [the outcome from the positioning statement].

Do these 3 things today:
1. Introduce yourself in [category]: [name, what you do, what you want from here]
2. [first classroom action with link]
3. [next live call: day + time]

[One line on how to get help / where to post questions]

[Sign-off]
```

## Field Documentation
| Field | Type | Notes |
|---|---|---|
| {group-name} | variable | Target group |
| [category] | prose | The intro/discussion label that exists in the group |
| [first classroom action] | prose | A real page from the classroom tree |

## Section Specifications
- **Minimum**: greet, remind them why they joined, ask for an intro post.
- **Pin it** and keep it under ~150 words.
