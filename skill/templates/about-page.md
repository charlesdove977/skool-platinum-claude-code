# About Page Template

## Contents
- Template block (fenced)
- Video (2–5 min) outline
- Description (below the video)
- Field Documentation
- Section Specifications

Output file: `skool-platinum/setup/{group-slug}/{YYYY-MM-DD}/02-about-page.md`

```template
# About page: {group-name}

## Video (2–5 min) outline
1. Hook: [who this is for + the outcome, in one sentence]
2. What it is: [the community in plain words]
3. What's inside: [3–5 deliverables, shown on screen]
4. Proof: [real member win or the owner's result]
5. Invite: [why join now + what happens after joining]

## Description (below the video)
[One-line positioning statement]

**Who it's for**
- [specific person 1]
- [specific person 2]

**What you get inside**
- ✅ [deliverable] - [why it matters]
- ✅ Live weekly Q&A - [benefit]
- ✅ Community - [benefit]
- ✅ Member map - [benefit]

**What members are saying**
- "[real testimonial]" - [first name + last initial]

[Closing line: the result + the next step]
```

## Field Documentation
| Field | Type | Notes |
|---|---|---|
| {group-name} | variable | Target group |
| Deliverables | prose | Only assets that really exist in the classroom/calendar |
| Testimonials | prose | Real only; pull from Wins posts; leave a marked slot if none |

## Section Specifications
- **Answer three questions only**: what is it, who is it for, why join.
- **Never include**: biography, external links, long paragraphs, AI filler phrases (see checklists/about-page-quality.md).
- **Voice**: the owner's voice (profile Voice section), no em dashes, short punchy bullets.
