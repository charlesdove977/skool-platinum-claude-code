# Setup Complete Checklist

## Contents
- Task 1: Positioning, deliverables, price
- Task 2–3: About page, description, cover
- Task 4–6: Start Here, classroom, kickoff

**Purpose:** Verify a group meets all 6 Platinum setup tasks before launch.

## Task 1: Positioning, deliverables, price
- [ ] Positioning statement names a specific person, a specific outcome and a method
- [ ] Statement passes the generic test (it could not describe any other group)
- [ ] Deliverables listed as "what's inside - why it matters", including the 3 Skool defaults
- [ ] Monthly price inside the niche band, or the deviation is justified
- [ ] Annual price is 20–40% below 12× monthly (if annual offered)

## Task 2–3: About page, description, cover
- [ ] About page has a 2–5 minute video
- [ ] About page passes checklists/about-page-quality.md
- [ ] Group description matches the positioning statement
- [ ] Cover shows benefit headline, niche signal and the owner's real face, readable in 1–2 seconds

## Task 4–6: Start Here, classroom, kickoff
- [ ] Start Here post pinned: welcome, why they are here, intro ask
- [ ] Classroom covers at least one of: course content, recorded calls, resources
- [ ] Nothing is being built pre-launch that members have not asked for
- [ ] Kickoff call scheduled on launch day with an agenda
